每个会话对应一个真实的 `memory.md` 文件，AI 回答前会把记忆注入上下文。

1. 右侧记忆面板可直接编辑，保存后立即生效（用外部编辑器修改也会被自动捕获）。
2. 对话积累若干轮后会自动提炼要点写入记忆，也可点「立即提炼」手动触发。
3. 切换模型时执行交接三步：读取记忆 → 选择注入策略 → 新模型带着记忆继续对话。

```
项目根目录/data/conversations/{会话id}/memory.md
```
