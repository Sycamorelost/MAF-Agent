## 四、合同高频条款词（增补）

> 英文合同中最易译错的固定表述，参照香港律政司《英汉法律词汇》与合同通行译法。

| 英文 | 中文 | 备注 |
| --- | --- | --- |
| liquidated damages | 违约金 | 约定损害赔偿，不译「清算损失」 |
| consideration | 对价 | 合同法语境，不译「考虑」 |
| estoppel | 禁反言 | |
| tort | 侵权行为 | |
| negligence | 过失 | |
| fiduciary duty | 信义义务 | 受托义务 |
| escrow | 第三方托管 | 常见 escrow account |
| lien | 留置权 | |
| severability | 可分割性 | 条款独立有效 |
| governing law | 管辖法律 | 亦译「适用法律」 |
| assignment | 转让 | 合同权利义务语境 |
| non-compete | 竞业禁止 | 常作条款名 |
| indemnification | 弥偿；补偿 | 使不受损失 |
| covenant | 契约条款 | 贷款/债券保护性条款 |
