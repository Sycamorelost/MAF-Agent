# 常用公式与数据透视思路

> 依据 Microsoft 官方文档整理。让 AI 写 Excel 公式、规划透视表或解释报表逻辑时引用本页。

## 一、查找类

| 需求 | 公式 | 说明 |
| --- | --- | --- |
| 按编号查姓名 | `=XLOOKUP(A2, 编号列, 姓名列, "未找到")` | 推荐：默认精确匹配、可向左查、可设兜底值 |
| 老版本兼容 | `=VLOOKUP(A2, 表区域, 2, FALSE)` | 只能向右查；第四参数务必 `FALSE` 精确匹配 |
| 按位置取值 | `=INDEX(列, MATCH(A2, 键列, 0))` | 灵活，列增删不易错位 |

## 二、条件聚合

| 需求 | 公式 |
| --- | --- |
| 单条件求和 | `=SUMIF(部门列, "研发", 金额列)` |
| 多条件求和 | `=SUMIFS(金额列, 部门列, "研发", 月份列, "2026-10")` |
| 多条件计数 | `=COUNTIFS(状态列, "完成", 负责人列, "张三")` |
| 多条件平均 | `=AVERAGEIFS(分数列, 班级列, "一班")` |
| 分支判断 | `=IFS(分数>=90,"优", 分数>=60,"及格", TRUE,"不及格")` |

注意：`SUMIFS` 的求和列在**第一个**参数，`SUMIF` 的在**最后一个**，混用最容易写反。

## 三、数据透视表四区域

1. **行**：分组维度（如部门、月份）。
2. **列**：交叉对比维度（如季度、地区），维度多时优先放行，保持表窄。
3. **值**：聚合指标，默认求和，可切换计数/平均/最大/占比（右键 → 值汇总方式/值显示方式）。
4. **筛选**：报表级过滤（如只看某一年）。

## 四、透视最佳实践

- 先把数据源转为**结构化表（Ctrl+T）**：新增行自动纳入透视范围，刷新即可（Alt+F5）。
- 源数据保持「一行一条记录」，不要合并单元格、不要小计行混入。
- 需要在透视结果外引用数值时用 `GETPIVOTDATA`，避免透视布局变动后引用错位。
- 日期字段可右键「组合」按月/季/年聚合；数值字段可按区间组合（如年龄段）。

## 五、高频文本处理

| 需求 | 公式 |
| --- | --- |
| 拼接 | `=TEXTJOIN("-", TRUE, A2:C2)` |
| 拆分 | `=TEXTSPLIT(A2, "，")`（新版本）/ 数据 → 分列 |
| 去空格 | `=TRIM(A2)`（不去 NBSP，NBSP 用 `=SUBSTITUTE(A2,CHAR(160),"")`） |
| 提取 | `=LEFT/RIGHT/MID(文本, 位置, 长度)` |
