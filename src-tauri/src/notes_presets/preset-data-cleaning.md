# 数据清洗常见规则

> 通用最佳实践整理。让 AI 清洗表格、写清洗脚本或审查数据质量时，按本页清单逐项核对。

## 一、文本规范化

1. 去首尾空白与不可见字符：普通空格、制表符、**不间断空格（NBSP，`\u00A0`）**、零宽字符。
2. 统一大小写策略（枚举值、国家代码通常全大写；姓名不强制）。
3. 统一全角/半角：数字与英文通常半角；中文标点场景保留全角。
4. 去重前先做**键标准化**：trim + 大小写折叠 + 全半角统一后再比较，否则"张三 "与"张三"会被当成两人。

## 二、空值与缺失

1. 统一空值表示：空串、`NULL`、`N/A` 只保留一种约定并写入文档。
2. **区分"缺失"与"0"**：未填写 ≠ 数值为 0；统计均值时缺失应剔除而非按 0 计。
3. 关键字段缺失的行：标记待补或剔除，保留处置记录，不静默丢弃。

## 三、日期与数字

1. 日期统一 **ISO 8601（`YYYY-MM-DD`）**；避免 `01/02/2026` 这类月日歧义格式。
2. 时间戳注明时区；跨系统交换建议 UTC 存储、展示层本地化。
3. 数字去千分位逗号；小数点位数统一；货币注明币种，不混用符号。
4. 百分比统一存小数（`0.35`）或百分数（`35%`）其一，并在表头注明。

## 四、校验与留痕

1. 取值域校验：枚举列只出现合法值；年龄、数量等在合理区间。
2. 唯一性校验：主键/订单号/身份证号不重复。
3. 一致性校验：同一实体的姓名、编号跨表一致。
4. **保留清洗日志**：改了哪些行、按什么规则改的，可追溯可回滚；原始数据只读，不动源头。

## 让 AI 清洗时的推荐指令

> 「按以下规则清洗这份数据：① trim 所有文本字段；② 日期统一为 YYYY-MM-DD；③ 空值统一为空字符串；④ 去重前先标准化键；⑤ 输出清洗报告：每条规则影响的行数。」
