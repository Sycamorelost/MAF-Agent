## 四、统计推断与机器学习（增补）

> 统计与 ML 论文中最易译错的术语，参照统计学通行译法与机器学习学界惯例。

| 英文 | 中文 | 备注 |
| --- | --- | --- |
| statistical power | 统计功效 | 不译「统计权力」 |
| effect size | 效应量 | |
| internal / external validity | 内部 / 外部效度 | |
| inter-rater reliability | 评分者间信度 | |
| null / alternative hypothesis | 原假设 / 备择假设 | |
| Type I / Type II error | 第一类 / 第二类错误 | |
| multiple comparisons | 多重比较 | |
| p-hacking | p 值操纵 | |
| selection bias | 选择偏倚 | |
| survivorship bias | 幸存者偏差 | |
| case-control study | 病例对照研究 | |
| intention-to-treat | 意向性治疗分析 | 缩写 ITT |
| reproducibility | 可复现性 | 与 replicability(可重复性)有区分 |
| robustness | 稳健性 | 正式文体优于「鲁棒性」 |
| ground truth | 真值 | ML 语境，不译「地面真相」 |

| baseline | 基线 | |
