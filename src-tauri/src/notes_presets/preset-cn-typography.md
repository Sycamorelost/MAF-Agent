# 中文排版与标点规范

> 依据 GitHub「中文文案排版指北」（sparanoid/chinese-copywriting-guidelines）、W3C《中文排版需求》(clreq) 与 GB/T 15834《标点符号用法》整理。写作、翻译收尾检查时引用。

## 一、空格规则

| 规则 | 正确 | 错误 |
| --- | --- | --- |
| 中英文之间加空格 | 使用 Git 管理代码 | 使用Git管理代码 |
| 中文与数字之间加空格 | 团队有 12 个人 | 团队有12个人 |
| 数字与英文单位之间加空格 | 容量为 500 GB，速度 100 Mbps | 容量为500GB |
| 数字与中文单位/％之间不加空格 | 占比 45%，温度 28℃ | 占比 45 % |
| 全角标点与其他字符之间不加空格 | 刚买了一部 iPhone，很开心。 | 刚买了一部 iPhone ，很开心。 |
| 专有名词按官方写法 | 豆瓣FM、WeChat、iPhone SE | 豆瓣 FM、iphone |
| 链接/行内代码两侧按中英规则处理 | 详见 `README.md` 文件 | 详见`README.md`文件 |

## 二、标点全半角

| 规则 | 正确 | 错误 |
| --- | --- | --- |
| 中文语句用全角标点 | 你好，世界。 | 你好,世界. |
| 不重复使用标点 | 太棒了！ | 太棒了！！！ |
| 英文句内用半角标点 + 空格 | Hello, world. | Hello,world. |
| 中文并列成分用顿号 | 支持 Windows、macOS 和 Linux | 支持 Windows, macOS 和 Linux |
| 省略号用 `……` | 等等…… | 等等... |
| 破折号用 `——`（占两格） | 他——出乎意料——同意了 | 他--出乎意料--同意了 |
| 数值范围用一字线或浪纹 | 第 3—5 页；100～200 元 | 第 3-5 页（连字符仅限复合词） |
| 百分号、度数紧贴数字 | 50%、37°C | 50 %、37 °C |

## 三、引号与书名号

| 规则 | 示例 |
| --- | --- |
| 中文用弯引号「」或 ""，全文统一 | 他说：「好的。」／他说："好的。" |
| 引号嵌套：外双内单（"" 体系） | 他说："'同意'这个词用错了。" |
| 书、刊、文章用《》〈〉 | 《红楼梦》、〈序言〉 |
| 英文作品名用斜体，不用书名号 | *Pride and Prejudice*（不写《Pride and Prejudice》） |
| 软件名/产品名不加书名号、保持大小写 | 使用 Visual Studio Code 开发 |
| 括号：中文语境全角（），英文语境半角 () | 中文（简体）／ Simplified Chinese (zh-CN) |

## 四、其他要点

- 时间日期写法统一：`2026-11-01` 或 `2026 年 11 月 1 日`，不混写 `2026/11/01`。
- 阿拉伯数字与汉字数字不混用：写「三」还是「3」全文统一（技术文档推荐阿拉伯数字）。
- 千分位：`1,234,567` 用半角逗号；中文语境也可写 `123 万`。
- 避免「的、地、得」混用；避免在中文里直译英文长定语从句。
