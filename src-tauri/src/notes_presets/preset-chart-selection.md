# 数据可视化图表选型速查

> 参照 FT Visual Vocabulary（Financial-Times/chart-doctor）、ECharts 官方文档、Data-to-Viz 整理。让 AI 画图表（ECharts）前先按本表选型。

## 一、图表 × 场景对照

| 图表 | 适用场景 | 避坑 |
| --- | --- | --- |
| 柱状图 (bar) | 类别间数值比较、排名 | 类别 >10 改用条形图；纵轴必须从 0 开始 |
| 条形图 (horizontal bar) | 类别名较长或类别多 | 按值排序更易读 |
| 折线图 (line) | 时间序列趋势 | 类别轴（非时间）勿用折线，会暗示连续性 |
| 面积图 (area) | 趋势 + 量级感 | 多系列重叠难读，优先堆叠或改折线 |
| 堆叠柱状/面积 | 总量 + 构成随时间/类别变化 | 非底层系列难以跨类别比较 |
| 饼图 (pie) | 简单占比构成（部分-整体） | 分块 ≤5 个；占比接近时改柱状 |
| 环形图 (donut) | 同饼图，中心可放总计 | 勿放多个环对比 |
| 散点图 (scatter) | 两变量相关性、分布 | 点过多用透明度/采样；相关 ≠ 因果 |
| 气泡图 (bubble) | 三变量（x、y、大小） | 面积编码易被低估 |
| 热力图 (heatmap) | 矩阵模式、密度（时段×星期） | 色阶须连续且有图例 |
| 直方图 (histogram) | 单变量分布 | 分箱宽度影响结论，需注明 |
| 箱线图 (box) | 多组分布对比、离群值 | 读者不熟时加注释说明五数概括 |
| 漏斗图 (funnel) | 阶段转化（注册→激活→付费） | 宽度须与数值成比例 |
| 桑基图 (sankey) | 流量/资金在多节点间流转 | 节点 >15 时杂乱；流量须守恒 |
| 树图 (treemap) | 层级占比（磁盘占用、预算构成） | 面积难精确比较，深层级用下钻 |
| 雷达图 (radar) | 多维画像（能力评估） | 维度 ≤8；不同量纲先归一化 |
| 瀑布图 (waterfall) | 增减归因（利润桥、预算分解） | 配色区分增/减/合计 |
| 甘特图 (gantt) | 项目排期、任务依赖 | 仅时间维度，资源负载另用热力图 |
| 地图 (choropleth) | 地理分布 | 用率值（人均/密度）而非绝对值 |

## 二、通用避坑清单

- 双轴折线：两条 y 轴可任意缩放制造虚假相关，除非确需对比且明确标注，否则拆成两张图。
- 3D 图表：透视扭曲数值感知，禁用。
- 截断坐标轴：柱状图纵轴不从 0 开始会夸大差异；折线图可不从 0，但应注明。
- 颜色：分类 ≤7 色；连续数据用单色调渐变；红绿搭配考虑色盲。
- 动画：仅用于叙事过渡，不用于精确读数场景。
- 一句话原则：每张图标题写出结论（「Q3 留存率回升至 42%」），而非名词短语（「留存率图」）。
