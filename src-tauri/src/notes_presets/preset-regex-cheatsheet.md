# 正则表达式速查

> 参照 MDN Regular expressions、regular-expressions.info、PCRE2 文档整理。让 AI 写匹配/替换/数据清洗规则时可直接引用本表。

## 一、元字符与字符类

| 语法 | 含义 | 示例 |
| --- | --- | --- |
| `.` | 任意字符（默认不含换行） | `a.c` 匹配 abc |
| `\d` `\D` | 数字 / 非数字 | `\d{4}` 四位数字 |
| `\w` `\W` | 单词字符 `[A-Za-z0-9_]` / 非单词字符 | `\w+` |
| `\s` `\S` | 空白（空格/Tab/换行）/ 非空白 | `\s+` |
| `[abc]` | 字符集（其中任一） | `[aeiou]` |
| `[^abc]` | 否定字符集 | `[^0-9]` |
| `[a-z]` | 范围 | `[一-龥]` 匹配 CJK 汉字 |
| `\b` `\B` | 单词边界 / 非单词边界 | `\bcat\b` 整词匹配 |
| `^` `$` | 行/串起始、结束 | `^#` 行首井号 |
| `\` | 转义元字符 | `\.` 匹配字面点 |

## 二、量词与分组

| 语法 | 含义 | 说明 |
| --- | --- | --- |
| `*` `+` `?` | 0+ 次 / 1+ 次 / 0 或 1 次 | 默认贪婪 |
| `{n}` `{n,}` `{n,m}` | 精确 n 次 / 至少 n 次 / n~m 次 | `\d{2,4}` |
| `*?` `+?` `??` | 懒惰（非贪婪）模式 | `<.*?>` 最短匹配 |
| `(abc)` | 捕获分组 | `\1` 反向引用 |
| `(?:abc)` | 非捕获分组 | `(?:https?)://` |
| `(?<name>abc)` | 命名分组 | `(?<year>\d{4})` |
| `a\|b` | 交替（或） | `jpg\|png` |
| `(?=...)` `(?!...)` | 正向前瞻 / 负向前瞻 | 见实战示例 10 |
| `(?<=...)` `(?<!...)` | 正向后顾 / 负向后顾 | `(?<=\$)\d+` 取金额数字 |

## 三、标志位（flags）

| 标志 | 含义 |
| --- | --- |
| `g` | 全局匹配（不在首个命中后停止） |
| `i` | 忽略大小写 |
| `m` | 多行模式（`^` `$` 匹配每行） |
| `s` | dotAll：`.` 也匹配换行 |
| `u` | Unicode 模式（`\p{L}` 等可用） |
| `x` | 忽略空白与注释（PCRE/Python，便于排版长正则） |

## 四、数据处理实战示例

| # | 场景 | 正则 | 说明 |
| --- | --- | --- | --- |
| 1 | 邮箱（简化版） | `^[\w.+-]+@[\w-]+(\.[\w-]+)+$` | 覆盖 99% 场景 |
| 2 | 日期 YYYY-MM-DD | `^\d{4}-(0[1-9]\|1[0-2])-(0[1-9]\|[12]\d\|3[01])$` | 校验月份 01–12、日 01–31 |
| 3 | 空白行 | `^\s*$`（配 `m`） | 删除/定位空行 |
| 4 | CSV 字段（含引号转义） | `(?:^|,)("(?:[^"]|"")*"|[^,]*)` | 兼容带引号和逗号的字段 |
| 5 | URL（http/https） | `https?://[\w.-]+(?::\d+)?(?:/\S*)?` | 含可选端口与路径 |
| 6 | 手机号（中国大陆） | `^1[3-9]\d{9}$` | 11 位，第二位 3–9 |
| 7 | 提取中文字符 | `[一-鿿]+`（或 `\p{Han}+` 配 `u`） | 清洗文本中的中文段 |
| 8 | 行首尾空白 | `^\s+\|\s+$`（替换为空串） | 实现 trim |
| 9 | IPv4 地址 | `^((25[0-5]\|2[0-4]\d\|1?\d?\d)\.){3}(25[0-5]\|2[0-4]\d\|1?\d?\d)$` | 每段 0–255 |
| 10 | 强密码校验 | `^(?=.*[a-z])(?=.*[A-Z])(?=.*\d).{8,}$` | 前瞻断言：含小写、大写、数字，≥8 位 |
| 11 | 千分位数字 | `\d{1,3}(,\d{3})*(\.\d+)?` | 匹配 1,234,567.89 |
| 12 | 连续重复词 | `\b(\w+)\s+\1\b` | 反向引用查 "the the" 类错误 |

## 五、避坑

- 贪婪匹配跨行吞噬：优先用懒惰量词或否定字符集 `[^>]*`。
- 忘记转义 `.` `[` `(` 等元字符。
- 超长文本上的嵌套量词（如 `(a+)+$`）会导致回溯爆炸（catastrophic backtracking），应避免。
