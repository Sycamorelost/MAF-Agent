# Markdown 表格语法速查（GFM）

> 依据 GitHub Flavored Markdown 官方规范（Tables 扩展）整理。让 AI 生成或修复表格时，可直接引用本页规则校验。

## 最小骨架

```markdown
| 姓名 | 部门 | 入职日期 |
| --- | --- | --- |
| 张三 | 研发 | 2026-01-15 |
| 李四 | 市场 | 2026-03-02 |
```

- 表头下一行**必须是分隔行**（`| --- | --- |`），列数与表头一致，否则渲染为普通文本。
- 首末的外层竖线可省略，但建议保留，源文本更易读。

## 对齐控制（写在分隔行）

| 写法 | 效果 |
| --- | --- |
| `:---` | 左对齐（默认） |
| `:---:` | 居中 |
| `---:` | 右对齐（数字列常用） |

## 高频坑

1. **单元格内的竖线必须转义**：`a \| b`；行内代码里的竖线同样要转义：`` `a \| b` ``。
2. **表格内不能多行**：一个单元格只允许一行文本；需要换行用 `<br>`。
3. **表格遇空行结束**：表格与上文之间留空行更稳，避免被上一段落"吞并"。
4. 分隔行的短横至少 3 个（`---`），冒号位置决定对齐，短横数量不影响效果。
5. 单元格内容支持行内格式（加粗、代码、链接），不支持标题、列表等块级元素。

## 快速修复清单

- [ ] 分隔行存在且列数与表头一致
- [ ] 内容竖线已 `\|` 转义
- [ ] 数字列右对齐、文本列左对齐
- [ ] 表格前后各留一个空行
